# DoneGate（完结门）· 写方路由

## 零、先读这段：判定核采证与纪律边界

> **【非工程问答直通退让（Stand-Down）】**：即便当前会话仍挂载完结门预设或已加载本技能，只要用户消息**不含 `[DG-TARGET]` 蓝色引用胶囊**且属于查天气、日常闲聊、通用常识问答等非软件工程请求，**必须立即按普通助手简明作答，严禁运行任何 `donegate` 命令，严禁生成画布节点、工作流或门禁微卡**。

你拿这份文件，通常是一轮活到了关口：要开工，要写判据，要收证据，或要交接。动手之前，先认清这套东西的分层形态：在完整仓库与公开包里，`runner/donegate.mjs` 零依赖判定核负责执行命令、写入互哈希证据三件套并从盘上材料现算五状态六栏总账（`INV-01`）；若你只安装了不含 `runner/` 的纯技能分发包，则六道门（门 0 起手、门 1 基线、门 2 判据、门 3 有牙、门 4 证据、门 5 复核）退化为操作卡流程纪律，必须照卡把真实命令与输出落盘。

下面几个词全篇反复出现，先各给一句人话解释。判据是一条能判断真假的命令，实际结果和事先写好的期望对得上才算过；判据失败叫红，通过叫绿。契约是一次可以独立验收的工作，有自己的代码范围和若干条判据。冻结指判据先写好、由人类裁方确认范围（`scopeAck`）并签字，实现过程中不许改；先写实现再补判据，等于让被检查的人自己出题。有牙指这条判据被故意改坏的实现真的弄红过；没红过的判据，判绿没有分量。写方是动手干活的一方，也就是读这份文件的你和你的 AI 会话。判方是另一个会话、另一个厂商的模型，复核时只看得见判据原文和运行输出，只答 pass、fail 或 unknown。总账是每轮收尾由判定核现算的一行状态统计。

三件连判定核也无法单靠机器替你兜住的事，先说清楚，不许含糊。第一件，机器能校对 `frozenHash`、材料指纹与证据链，但判不了「你写的判据范围是不是故意避开了核心难点」——这必须靠冻结前人类裁方逐条确认 `scope` 并签字（`G-10`，禁止写方或 AI 自己代签）。第二件，机器能跑 `breakPatch` 与变异测试，但若写方同时控制源码、测试与补丁，仍可能构造表面有牙的弱断言——这必须靠门 5 异构模型独立复核（`donegate-judge`）。第三件，使用 `--skip-gates` 或 `--allow-dirty` 的调试运行绝不算正式验收（判定核会将脏树证据拒之门 4 之外）。

正因为单边自测挡不住同源盲区，未经独立判方复核与裁方签收的结论一律按 `../设计/adr/007-自评结论必须降一档并披露.md` 降一档采信。一句话概括它的能力边界：它把「做完没有」变成可复算的盘上证据，让你少骗自己一点，但不替你写代码、也不承诺加速。

## 一、四条不许（整份 skill 唯一绝对的话）

整份技能里只有这四条是绝对的话，其余内容都只是「走到哪一步、读哪张卡」的指引。

1. 不许把「流程走完了」说成「验收通过了」。判据跑完，状态只有五个词：未验证、通过、未通过、过期、无法判断。`通过` 之上没有更强的词；`通关` 是挂在通过上的一个标记，不是第六个状态。
2. 不许由写方推状态。状态从材料现算，材料摆在哪、算出哪个就是哪个；算不出来就写 `无法判断`，不许估、不许猜。
3. 不许改判据不重签。判据改一个字符就要重新签；没重签的判据，状态是 `无法判断`，不是 `过期`。例外（INV-15、§3.5 定案 A）：在「过期」状态下改写判据且未重签，状态转 `未验证`。四个状态别互相顶替。
4. 不许用 `|| true`、`continue-on-error`、只打 warn 的写法让判据变绿。命中这一条，直接判红。

## 三、一轮的固定动作（七步，与 `02-规格.md` §9.1 逐条对应）

一轮工作有七个固定动作，做完才算一轮。每步括号里的是时间预算。

1. 读 `INTENT.md`、`CONSTRAINTS.md` 和交接包（2 分钟）。`INTENT.md` 记这个项目为什么做、什么算成功；`CONSTRAINTS.md` 记不许碰什么、必须守什么；交接包是上一轮留给这一轮的交接文档。
2. 跑冒烟，确认基线绿（1 分钟）。冒烟是一条最快确认项目整体还活着的最小命令，基线是你动手之前项目已有的状态。冒烟红就先修基线，这一轮不接新活。
3. 只挑一个契约，不许多挑。
4. 跑该契约全部判据，拿真实退出码，按第五节的要求把结果落成证据。
5. 判方复核（5 分钟，怎么做见门 5 卡）。
6. 更新交接包与缺口清单（2 分钟）。缺口清单列的是项目当前欠的账，也就是还没做或已经烂掉的事；门 0 靠它判断这一轮挑的契约是不是该做的那一个。
7. **写决策记录**——只在这一轮改了判据、边界或意图时写（3 分钟）。它是一篇短文，说明改了什么、为什么改，留给后续轮次查。

第 3 步值得单独强调：一次会话一个契约，是这套东西里最省事又最有效的一条（§9.1 原话）。

## 四、五个状态词与六栏总账

每轮收尾，你要贴一句总账：一行字，报告这一轮的判据各落在什么状态。状态词与总账的定义不在本文件里，定义在 `../设计/02-规格.md` §三；`通过` 的四个子数在 §3.4.1，机器可读的权威是 `tools/classification.json`（私有仓）。

总账格式固定，逐字贴，不许改写：

```text
本轮 N 项：通过 A、未通过 C、未验证 D、过期 E、无法判断 F、不稳定 G
其中通过里：算数 A1、无牙 A2、未做实验 A3、待重验 A4
```

四个子数各指什么：`算数` 是可信的通过（做过有牙实验、也不用重验）；`无牙` 是跑绿但改坏实验暴露了判据没牙；`未做实验` 是跑绿但从没做过改坏实验；`待重验` 是跑绿但材料上游变了，结论要先重跑再信。

六栏相加必须等于 N（INV-16）。加不起来就是算错了，回头重算，不许凑。`不稳定` 是第六栏、占分母：同一条判据连续三次运行结果各不相同就归入这一栏；它不是五个状态词之外的附注，是一条要人去看的信号。

两行里的 `N`、`A`、`C`、`A1` 全是占位符，必须换成实数再贴。本轮 3 条判据全绿、三条都做过改坏实验时，总账该写成：

```text
本轮 3 项：通过 3、未通过 0、未验证 0、过期 0、无法判断 0、不稳定 0
其中通过里：算数 3、无牙 0、未做实验 0、待重验 0
```

照抄占位符等于没算。试点实测里，五轮连做的样本有 45/80 把 `N` 原样抄进了总账，那一行根本加不起来。

## 五、证据的最小要求

判据每跑一次，要留下三份文件才算证据：`start.json`（运行前记现场）、`report.json`（运行后记结果）、`end.json`（收尾记录）。三份文件互相哈希链：后一份里记着前一份的哈希，改了其中任何一份，后面的链就对不上。断任何一环，整份证据判 `无法判断`。

`report.json` 里的退出码必须是子进程直读的，不经任何包装层。你经 `npm` / `pnpm` / `npx` 跑判据时，取到的是包装层的退出码，不是判据本体的；包装层什么时候替换掉这个码，你控制不了，判据就变成装饰。（2026-11-19 复测过 7 条路径，没有复现「包装层把退出码吞成 0」；所以这条纪律的理由落在更稳的那句话上：问题从来不是「本机会吞」，是「哪一层的码不可控」。）

## 六、自检：这个仓库自己的四条

这个仓库（装着本技能与全部设计的档案库）自己带四条基础结构自检。你改了文档或工具之后，在仓库根目录把四条全跑一遍（完整开发仓建议直接跑第八节的 `check-escapes.mjs --self-check` 全套自检），退出码 0 才算这一轮干净：

```text
node "tools/check-package.mjs（私有仓）"   结构与链接
node "tools/verify-spec.mjs（私有仓）"     规则本身
node "tools/check-rot.mjs（私有仓）"       文档腐化（13 条检查）
node "skill/check-skills.mjs"    本技能到底能不能被加载
```

作者仓库另有 `skill/check-plan.mjs`（不在公开分发包内）一类持续检查脚本，它们依赖不随包分发的材料，不是使用者的自检。

但全绿只证明档案自洽，不证明设计有效。这句话写在 `../设计/adr/007-自评结论必须降一档并披露.md` 里。

## 八、漏网复盘与自迭代（五步闭环）

若门禁全绿仍出线上/真机缺陷，修完症状后须走完五步闭环，禁直接提交：
1. **定位盲区**：查清全绿漏检根因（跨平台路径/换行、边界顺序、工具参数等）。
2. **同类横扫**：按同一根因排查其余脚本、卡片、适配器与模块，一次清净。
3. **补独立门禁**：编写先红后绿的复现检查，运行 `node <DoneGate根>/skill/check-escapes.mjs --record ...` 记入 `.donegate/escapes.jsonl`。
4. **全仓自检**：提交前必跑 `node <DoneGate根>/skill/check-escapes.mjs --self-check --project .`，未全绿禁 `git commit`。
5. **反馈上游**：若盲区属 DoneGate 自身，征得用户同意后运行 `node <DoneGate根>/skill/check-escapes.mjs --report-template` 生成脱敏草稿，可用 `gh issue create --repo Zegel-None/DoneGate` 提交。

## 十一、DeepSeek Harness Web 协同

1. **总控与执行隔离**：主会话（`dsh-donegate-router`）解析底部输入框蓝色引用胶囊（`[DG-TARGET uri=dg://...]`）、查 `status/gaps` 并通过 `subagent` 派发隔离执行端（`dsh-donegate-worker`）；执行端仅在契约 `scope[]` 内改码过 `0/1/2/3` 门禁，连续失败按干净摘要重启。
2. **微卡与卡包顶栏**：`@local/dsh-donegate` 挂载会话「完结门」视图（`order: 85` 后置不抢占默认聊天）与输入框开关；未建会话或处于原生聊天视图时抽屉默认失活返回 `null` 零遮挡；节点回执经盘上 `.receipt.json` 64 位指纹核验后浓缩为两行微卡。
3. **非工程问答直通退让**：若用户忘了切回默认预设，只要消息不含 `[DG-TARGET]` 蓝色引用胶囊且属查天气、日常闲聊等非软件工程请求，直接按普通助手作答，禁跑 `donegate` 命令与门禁微卡。

## 十二、小模型增量提交纪律（`pre-commit` 强拦）

1. **先装钩子**：首次接手存量仓先跑 `node <DoneGate根>/skill/install-hooks.mjs --root .`。
2. **单步预算**：单次提交新增代码 `<=300` 行、涉及源码文件 `<=8` 个、单文件有效代码 `600` 行预警 / `850` 行硬顶（见 `thresholds.json`），禁使用 `// ... existing code ...` 省略逻辑。
3. **禁凑绿与野文件**：禁 `.skip/.only/.todo`、恒真断言、linter 豁免、`TODO/FIXME` 或空 `catch {}`；临时脚本仅放 `.donegate/scratch/`；新增业务源码须归入活跃契约 `scope[]`（未认领文件用 `check-commit-hygiene.mjs --quarantine` 隔离）；特例逃生须写 `// dg-allow: <至少6字原因>`。

## 十三、密封契约切片与阅后即焚局部派工（禁扫全仓）

任何零记忆会话或子代理接手项目时，**严禁开场通读全仓目录源码**，统一走三级渐进上下文流水线（默认按 `1M 窗口 × 40% = 400,000 Tokens` 五段预算配额）：

1. **先读 L0 路由表定位目标卡**：运行 `node <DoneGate根>/runner/donegate.mjs slice --router-only --root .`，仅读生成的 `.donegate/ROUTER.md`（约数百 Tokens）确定目标节点 `nodeId` 与上下游拓扑。
2. **领单卡 L2 密封胶囊局部读写**：运行 `node <DoneGate根>/runner/donegate.mjs slice <nodeId> --freeze-stub --root .`（小窗口子代理可加 `--context-window 128000 --utilization 0.4`），只读 `.donegate/capsules/<nodeId>.capsule.md`（本卡 `0-Hop` 全量源码与关联单测 `160k` + 上下游 `1-Hop` 含 JSDoc 的只读 `.stub.d.ts` 存根 `48k`；`2-Hop` 以外节点物理屏蔽）。
3. **跑单卡微门禁并交回轻量回执**：改码后执行 `node <DoneGate根>/runner/donegate.mjs check-node <nodeId> --allow-dirty --receipt --root .` 拦截越界改文件、私改冻结导出签名、跨门面私引与未声明红线依赖；退出码为 `0` 后，子代理只将 `500` Tokens 以内的结构化 JSON 回执交回总控并销毁子会话上下文。
