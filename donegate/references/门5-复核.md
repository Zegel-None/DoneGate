# 门5-复核（写方侧准备）

写方在门 5 之前把什么装进复核包、把什么剔出去；判方怎么判不在这张卡，在 `donegate-judge`。

## 入口条件

1. 门 0 至门 4 已各自过完，**判据的** `claim` / `observable` / `scope` 三件套已写定（定义见 规格（调研/评审材料，不在公开分发包内） §6.1；它不是契约字段，别往 `contract.json` 里加）。
2. 已经能说出 `base..head` 两个版本号的具体值，而不是「当前最新」这类相对说法。
3. 每条判据都能照原文跑一次，并留下运行输出与退出码。
4. 已知哪些材料自己给不出——给不出的那几份要能指名，不能留到判方那边才发现。

## 步骤

1. **先冻结两个版本号**。`base` 与 `head` 各写一个确定值；包里所有材料都挂在这对版本号上，换了版本号就重打包。
2. **收集「给」的四样**：判据原文（含 `expect`）、`base..head`、运行输出与退出码、契约的 `scope` 与 `why`。四样逐样点名，缺哪样就记进缺口清单（边界见 §7.4）。
3. **原样录退出码**。每条判据跑它自己的原始 `node scripts/…` 命令，退出码只许落在 0 / 1 / 2 / 3（§八）。跑出来是红就记红，不许为了好看换命令或重跑到绿。
4. **剔除「不给」的四行**（§7.4 原表就是四行）：写方的计划、写方的对话历史、写方的思路·推理·草稿（**这三样在规格里是同一行，不要拆成两类数**）、其他契约的任何内容。判不准一份材料算「材料」还是算「思路」时，按不给处理——默认值是剔掉。
5. **一份契约只装自己的东西**。每段材料注明归属哪一个契约；没有归属的段落直接删。
6. **不写结论**。包里只放事实，不放写方对任何一项的判定；判定由判方按 §7.1 作答 `pass` / `fail` / `unknown`。
7. **先认自己缺的**。已知某份材料给不出，就在缺口清单里写清缺的是哪一份文件，不写「材料不足」了事（§7.3 的落地检查也管写方）。
8. **交之前过一遍四样齐、四类无**；若 `catch` 捕获到非预期行为改动，附一句大白话异常微追问交由裁方拍板确认。

## 出口判据

1. **四样齐**：包内能逐一点出判据原文（含 `expect`）、两个版本号、运行输出与退出码、契约的 `scope` 与 `why`；少于四样即失败。
2. **版本号是值不是描述**：两个版本号位置出现「最新」「HEAD」「当次提交」这类相对写法，失败。
3. **退出码只用四值**：包内每个退出码都在 0 / 1 / 2 / 3 之内；出现别的数字，失败；**但 `kind: human` 的判据本来就没有退出码，不算失败**（§2.4）——只有 `kind: command` 的判据缺退出码才算失败。
4. **禁给四类无残留**：在包内检索「计划」「思路」「草稿」「对话历史」（**只在非判据原文的部分检索**——判据的命令里可能合法地含这些词），以及**不属于本契约的契约 id**，命中即失败，命中处按「不给」删掉再交。
5. **每段有归属**：逐段核对注明的契约 id，出现无归属段落失败。
6. **缺口指得出来**：缺口清单每一条都能指名缺哪一份文件；指不出来失败。

## 业界做法参考

| 参考项目 / 条目 | 它做到哪一步 | 本卡与它的差异 |
|---|---|---|
| superpowers · `requesting-code-review`（F2 首选） | 派发审阅时只传「改了什么一句话 + 需求或计划 + `base..head` 两个 SHA」，并明令禁止把作者本次会话的历史交给审阅者 | 同样冻两个版本号、同样砍会话历史；但它允许传「计划」，本卡把写方的计划列进不给 |
| superpowers · `code-reviewer.md` | 规格只说要做什么，规格没覆盖的按合理使用者的预期判；结论前还须列出「考虑过但判定不归本次审阅」的行为 | 本卡不管判方怎么判，只保证判方手上一定有判据原文与 `scope`，而不是靠作者转述 |
| Stryker Mutator（F2 备选） | 唯一算数的是故意改坏后真的红一条，作者叙述与代码自洽换不来通过 | 方向一致；本卡不产生变异体，只把「改坏后红过」的运行输出与退出码作为必给材料搬过去 |

第一行的差异明显（计划给不给），按 ADR-015（调研/评审材料，不在公开分发包内） 用同一个量（判方每份复核要多读几份材料）比两边代价：

| 方案 | 正确性 | 代价 |
|---|---|---|
| 照它传「计划」 | 判方顺着作者的框判 | 判方多读 0 份；但作者计划写偏时，判成通过的那几次从材料侧看不出来，次数不可界 |
| 本卡不给计划 | 判方按判据原文与 `scope` 独立判 | 判方每份复核多读 1 份契约（`claim` / `observable` / `scope`），有界 |

多读 1 份是有界的，误判次数不可界，所以取后者。
