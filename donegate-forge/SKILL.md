# DoneGate 搭积木工坊（Forge · 普适适配与卡片封装标准）

## 零、这份技能解决什么

DoneGate 由**防伪判定核底座**与**可视化完结门画布**组成：外部千姿百态的 GitHub 开源项目（无论是命令行检查器、代码/SBOM 生成器、自带庞大 Web UI 的工作台、容器/状态机运行时，还是纯文档形态的设计规范与 Agent 技能集）都通过统一的**「薄适配器 + 模块化卡片声明」**接入系统。

为避免规范定得太死导致特殊项目接不进来，本工坊遵循**「严守防伪底线，彻底放开项目形态」**的普适设计：
- **死守的三条底线**：① 适配器只上交客观产物、提取物与观测事实，绝不越权输出 `verdict / passed / score` 等业务结论；② 适配器只许返回 `0（成功产出声明）/ 2（协议事故）/ 3（环境或上游无法判断）`；③ 必填「它不覆盖什么」（`blindSpots`），所有输入输出文件计算 64 位裸 SHA-256。
- **完全放开的形态自由度**：不强制要求本地二进制 CLI（支持无头导出、HTTP 接口快照、静态产物读取与纯规则提示词挂载）、不限语言、支持 `1–20` 任意阶段开发流与跨阶段通用底座复用、无需改任何前端源码即可通过 JSON 生成画布卡片与整条开发流。

## 一、四条边界（先认下再动手）

1. **适配器只产声明与提取物，不产业务评语**（adr/002（调研/评审材料，不在公开分发包内））。`claim.json` 里出现状态禁词键名，核侧直接退 `2`。
2. **砂浆只许三值退出码 `0 / 2 / 3`，永不返回 `1`。** 上游发现的违例、差异或生成的工件一律如实写进 `observation.json`、`artifacts[]` 与 `claims[]` 并退 `0`，由下游或判定核裁决。
3. **去壳取核：不抄代码、不 fork、不嵌套外部重 UI。** 遇到带 UI 的项目，优先抽无头导出命令、次选抽 HTTP 数据快照、兜底抽落盘文件，不在画布卡片里套娃别人的前端页面。
4. **互补并存（覆盖族），真重复才二选一。** 数据源、扫描对象、语言或精度不同的工具允许组成「覆盖族」并配归并卡；只有四维重合的重复工具才精简淘汰。

## 三、一轮接入的固定六步（任意 Agent 照此执行）

1. **栈盘点与缺口框定**（10 分钟）。写清三句话：「当前开发流哪一环缺什么产出或观测、现在靠什么兜底、接进来后给哪条判据或哪个下游节点提供实锤输入」，同时按 P4 写清它**不覆盖什么**。
2. **候选调研**（20–30 分钟）。核查 LICENSE 原文、维护活跃度与真实提取面（CLI 无头参数 / HTTP 接口 / 落盘文件 / 规则文档），标注【实测】或【盘上】档位；若多款工具数据源或对象互补，按覆盖族并存编排并规划下游归并卡。
3. **选型判定**（10 分钟）。确定归属哪一类普适形态（`scanner` / `generator` / `ui-extract` / `runtime-service` / `knowledge-skill` / `aggregator`），若是带 UI 或常驻服务项目，明确采用哪一层「去壳取核」方案。
4. **造适配器**（30–90 分钟）。用 `node skill/new-adapter.mjs <tool> --archetype <形态>` 一键生成 ≤45 行薄适配器骨架与 `bricks/<tool>/capabilities.json` 卡片端口配置；如需编排整条开发流，同步写入 `workflows/<id>.workflow.json`。
5. **三组必红夹具**（20–40 分钟）。验证映射反转必红、上游/输入缺失退 `3`、产物损坏或截断退 `3`，另附非法 `--registry-id` 退 `2`。
6. **登记与准入**（15 分钟）。写入 `adapters.registry.json`、`bricks/<tool>/capabilities.json`、`ledger.json`（未绑定硬判据前可先标 `advisory` 供开发流使用），跑通 `check-declarations`、`check-brick-capabilities` 与 `check-brick-liveness` 全部退 `0`。

## 四、收尾：这一轮交付什么才算完

```text
① 形态与提取声明：形态=<archetype>；提取面=<CLI/无头导出/API快照/规则包>；不覆盖=<blindSpots>
② 卡片与开发流落盘：bricks/<tool>/capabilities.json（含输入输出端口）+ 可选 workflows/<id>.workflow.json
③ 门禁真跑读数：new-adapter / check-declarations / check-brick-capabilities / check-escapes --self-check 全退 0
```
