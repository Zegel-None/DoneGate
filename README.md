# DoneGate（完工门）0.2.0

**一句话**：用 AI 写代码时，把「AI 嘴上说做完了」变成**「先定好怎么算完，跑出真实结果给你看」**。

---

## 你是不是也遇到过这些事？

- AI 自信满满地说「全部搞定了」，你一打开页面还是报错，或者修好了一个地方却把昨天的老功能弄坏了。
- 你让 AI「顺便跑一下测试」，它其实只跑了一半、或者干脆在写完代码之后把测试标准改松了来凑通过。
- 项目连续做了一周、几十轮对话下来，开个新对话就全忘光——哪些功能真的测过、哪些只是 AI 觉得「应该没问题」，谁也说不清。

**DoneGate 就是治这个的。** 它不是帮你写得更快的工具，而是帮你在**「到底做完没有」**这件事上少踩坑的验收助手。

---

## 装上之后，它会怎么帮你？

这是一套给 AI 看的**工作习惯与验收技能**（不需要 `npm install`，也不用跑什么后台服务）：

1. **先定标准，再写代码**
   每做一块新功能前，AI 会先和你确认「做成什么样才算完」、要跑哪些检查、哪些地方不能碰，并把标准锁死。写代码过程中不许临时改标准。
2. **必须真跑过，而且证明检查不是摆设**
   AI 说「做完了」之前，必须把检查真跑一遍、留下运行记录；而且要证明这套检查在代码故意写错时真的能抓出来（不是永远绿灯的假检查）。
3. **不信第一个 AI？叫第二个独立 AI 来复核**
   如果你不放心，可以手打 `/donegate-judge` 叫来一个全新的独立 AI 帮你查账。它只看原始的验收标准和实际运行输出，不听第一个 AI 的解释和废话，只给你三个答案之一：**通过 / 不通过 / 证据不够**。
4. **随时能交接、能查账**
   想新开对话、或者隔了几天回来继续做，直接让它打包交接或列出「哪些做完了、哪些还没测」，不用从头翻聊天记录。

---

## 用之前先说实话（它的边界）

这套公开版是**纯技能版**（本质上是写给 AI 的说明书，没有硬性拦截程序），有两件事得提前说清：

- **它管不住「偷懒挑简单题测」**：如果 AI 自己把检查范围划得很小，只测最容易过的部分，检查虽然全绿，但漏掉的地方还是会坏。
- **它不保证 AI 变老实，也不提升写代码速度**：它的作用是让证据摆在明面上、方便你和独立 AI 核对，而不是把 AI 变成 100% 不犯错的机器。

## 怎么安装

### 第一步：下载到本地

找一个专门放 AI 技能的文件夹，把仓库克隆下来（**注意不要多套一层文件夹**，打开这个目录时应该直接看到 `donegate` 和 `donegate-judge`）：

```powershell
git clone https://github.com/q862877400-ux/DoneGate.git D:\skills\DoneGate
```

### 第二步：告诉 DSH 去哪里找它

打开你的 DSH 配置文件（`%DSH_HOME%\profiles\web\cordis.patch.yml`，没有就新建一个），加上这几行：

```yaml
- id: skill
  config:
    customSkillDirs:
      - D:\skills\DoneGate
```

保存后重启 DSH，或等目录自动刷新即可。

---

## 平时怎么用

装好后，直接用自然语言跟 AI 说话就行：

- **开始新功能前**：「帮我定一下这轮的验收标准」
- **AI 说做完时**：「这轮做完了吗？」/「把证据和没测的地方列出来」
- **想让另一个 AI 独立复核时**：直接输入 `/donegate-judge`
- **准备开新对话时**：「帮我做个交接」

---

## 想确认自己装对了？（可选）

如果你习惯用命令行，可以在 `DoneGate` 目录下跑这四条检查，全部显示通过就说明文件完整、AI 也能正常加载：

```text
node tools/check-package.mjs               # 检查目录结构和文档链接
node tools/verify-spec.mjs                 # 检查验收规则本身是否自洽
node tools/check-rot.mjs                   # 检查文档描述有没有过期
node skill/check-skills.mjs --root .       # 检查 AI 能不能正常加载这两个技能
```

## 仓库里有什么

| 目录 / 文件 | 是什么（给人看的说明） |
|---|---|
| `donegate/` | 主技能：教 AI 怎么定验收标准、留证据、做交接 |
| `donegate-judge/` | 独立复核技能：只用 `/donegate-judge` 触发，负责冷酷查账 |
| `设计/`、`参考/` | 背后的规则原文与依据（给 AI 按需查阅的，你平时不用翻） |
| `tools/`、`skill/` | 上面那四条自检脚本和配套说明 |
| `README.md`、`CHANGELOG.md`、`VERSION`、`LICENSE` | 本说明、更新记录、版本号、MIT 开源协议 |
