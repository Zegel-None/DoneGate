# DoneGate（完工门）0.2.0 · 纯技能版

**一句话**：一个人的长周期项目里，把「这一轮做完没有」从**人回忆**换成**一份冻结的判据加一次真实运行**。

判据、契约、冻结三个词会反复出现。判据是一条能判断真假的命令，实际结果和事先写好的期望对得上才算过。契约是一次可以独立验收的工作，有自己的代码范围和若干条判据。冻结指判据先写好、由人签字，实现过程中不许改；先写实现再补判据，等于让被检查的人自己出题。

如果你更怕的是「以为做完了、其实没做」，而不是「做得慢」，这套工具才对你有用；它只治前一种失败，不提升生成速度。

## 它怎么工作（简要）

装好之后，一轮工作依次过六道门，每道门都是你必须自己回答的问题：门 0 起手（意图与约束落盘）、门 1 基线、门 2 写判据并冻结、门 3 有牙实验、门 4 收证据、门 5 判方复核。有牙指这条判据被故意改坏的实现真的弄红过；没红过的判据，判绿没有分量。

干活的人叫写方，不能自己写判据、不能自己推状态；复核由判方做：另一个会话、另一个厂商的模型，只看得见判据原文和运行输出，只答 pass/fail/unknown。每条判据跑完落在五个状态之一：未验证 / 通过 / 未通过 / 过期 / 无法判断，没有第六个。

**这个仓是纯技能版**：技能是给 AI 读的说明书，没有钩子、没有拦截、没有运行器替你采集证据。经它得出的任何结论，按 [设计/adr/007](设计/adr/007-自评结论必须降一档并披露.md) 一律降一档采信——那是包里的决策记录「自评结论必须降一档并披露」，结论都是作者自评、没有第三方复核。

## 用之前请先认下这三条硬伤

能力边界与实测数据的完整版见 [设计/07-结论.md](设计/07-结论.md)。它能压住「代码与判据」这一层的自欺；**「文档与交接」那一层压不住，而长周期项目主要烂在那一层**。另有三条硬伤：

**硬伤一：判据的覆盖范围由写方自己定**（`skill/06-机械化需求清单.md` 的 M-18）。写方可以合法地缩小 `scope`（判据声明「不管哪些行为」），让判据全绿、证据链对、总账加得起来，但没覆盖会坏的行为。红队实测蒙混率 **79%**。技能版治不了——规则写在散文里，被试可以不读；只有插件版能机械化。**用之前请认下这一条。**

**硬伤二：诚实层没有改善。** 实测里假称完成的比例是 10–20%，两次针对性修法都失败、已撤回；这套技能让材料可核，但没有让人更诚实。

**硬伤三：M-02 的前提待勘误。** 文档里写着「经 pnpm 跑会把退出码吞成 0」；2026-11-19 复测 7 条路径未复现，措辞正在按实测改写。有一条纪律在任何情况下都不会错：自己跑判据时直跑本体（`node <脚本>`）。

## 怎么装

**只克隆这一个目录，把它当「技能根」。** 技能根指直接子目录就是 `donegate/` 与 `donegate-judge/` 的那一层——**多套一层，DSH 加载器永远扫不到，而且不留任何日志**。

```powershell
git clone https://github.com/q862877400-ux/DoneGate.git D:\skills\DoneGate
```

在 DSH 的 profile patch 文件（`%DSH_HOME%\profiles\web\cordis.patch.yml`，没有就新建）里加：

```yaml
- id: skill
  config:
    customSkillDirs:
      - D:\skills\DoneGate
```

重启 DSH 或等目录刷新。装好之后卡片里的相对链接天然全部可达。

## 装完怎么验（四条自检，都要退出码 0）

```text
node tools/check-package.mjs                       # 结构、章节、链接
node tools/verify-spec.mjs                         # 规则本身
node tools/check-rot.mjs                           # 文档腐化
node skill/check-skills.mjs --root <技能根>         # 技能真的能被加载吗
```

**第 4 条别省。** 前三条只查包的结构与文档，全绿也不代表技能装对了：冷启动实测里 3 个从没接触过这个项目的接收方各自装了一遍，其中两个把整包多套了一层，前三条照样全绿。

## 这个仓里有什么

| 路径 | 是什么 |
|---|---|
| `donegate/` | 写方技能：路由器加 15 张操作卡（门 0–5、交接包、状态与功能树，另含 6 张模板） |
| `donegate-judge/` | 判方技能：只能手打 `/donegate-judge` 调起，材料受限、只答 pass/fail/unknown |
| `设计/` | 规则原文（02-规格、07-结论、adr 等）；卡片引用的规则节号在这里 |
| `tools/` | 三条自检脚本：结构、规则、文档腐化 |
| `skill/` | 三份与规则配套的说明与自检：规格缺口定论、机械化需求清单、技能加载自检 |
| `参考/` | **只留 3 份被设计文档直接引用的证据**：67 条问题的逐条处置、工具覆盖审计、串联失效链台账 |
| `README.md`、`LICENSE`、`CHANGELOG.md`、`VERSION` | 本页、MIT 授权、变更记录、版本号 |

**这个仓刻意不带的东西**：67 条问题的 14 份分册与 225 条解法分册、方法论横评、工具横评、五轮评审记录、试点读数与评分器。那些是作者的调研与过程材料，留在私有仓；正文里指向它们的 20 处链接已降级为纯文本并注明「（调研/评审材料，不在公开分发包内）」，所以**本仓内 0 死链**是可核的，而不是靠豁免名单糊出来的。
