# DoneGate 搭积木工坊（Forge）

## 零、这份技能解决什么

DoneGate 本体是**防伪裁判底座**：零依赖判定核只认自己的判据与证据，外部工具一律经由薄适配器上交「客观观测」，无权下结论。而**每一块新砖（外部工具）接到这个底座上，都有一套固定动作**——要先调研它值不值得接，再按砂浆协议写适配器，再配三组能红的夹具，最后登记入网并接受淘汰考核。

这套动作以前散在 `skill/17-砂浆适配器协议.md`、`skill/15-砖头接入策略.md` （私有仓）与各份调研报告里，只有读过全部文档的人（也就是作者自己）做得出来。**本技能把它变成六步可照做的流程**，让长尾技术栈（iOS、Rust、嵌入式、桌面端……）的使用者能自己给判定核加砖，而不用改判定核一行代码。

**它不做的事**：不产状态、不产 verdict、不替你决定「这块砖该不该接」的最终判定（那是你，也就是人）。

## 一、四条边界（先认下再动手）

1. **适配器只产声明，不产状态**（adr/002（调研/评审材料，不在公开分发包内））。`claim.json` 里出现 `verdict` / `score` / `ratio` / `passed` 这类键，核侧直接退 `2`。
2. **砂浆只许三值退出码 `0 / 2 / 3`，永不返回 `1`。** 上游扫出的业务违规一律写进 `claims[]` 并退 `0`，由核裁决；退 `1` 等于让适配器越权做业务判定。
3. **不许抄代码、不许 fork、不许 patch 上游。** 只许「原样安装 + 读它的产物」。业主 2026-11-20 的政策：完整接入（可用部分能力），抄机制不再是合法选项。
4. **一次只接一块砖。** 一轮会话接两块以上，夹具与登记必然串味，出问题也定位不到。

## 三、一轮的固定动作（六步，对应上面六张卡）

1. **栈盘点与缺口框定**（10 分钟）。先用一句话写清「缺什么能力、现在靠什么兜、补上以后**哪一条判据能从『无法判断』变成有读数**」。答不出第三问，这块砖就是装饰，直接退。
2. **候选调研**（30 分钟，最多 3 个候选）。每条候选必须标注证据档位：**【实测】**＝本机跑过 /**【盘上】**＝读过仓库与 README 原文 /**【声称】**＝只看了 README 简介。只标【声称】的候选不许直接进第 3 步。
3. **选型判定**（10 分钟）。三种接法选一种：A 完整接入用到全部 / B 完整接入只消费部分能力 / C 不接、自己写（C 必须给两个代价）。**选 C 要在决策记录里留痕，不许悄悄自研。**
4. **造适配器**（60–120 分钟）。照砂浆协议写薄转换层，只吃上游的机器可读产物，落严格九字段 `claim.json`。写完先 `--dry-run` 看形状，再在干净树上真跑一次。
5. **三组必红夹具**（30–60 分钟）。映射反转必红、上游缺失退 `3`、产物截断退 `3`，另加非法 `--registry-id` 退 `2`。**夹具自己要先红后绿**——第一版夹具必须真的红，否则它守不住任何东西。
6. **登记与准入**（20 分钟）。`adapters.registry.json` 一条、`ledger.json` 一条、`batches.jsonl` 记批次，跑 `check-declarations --verify-adapters` 与 `check-brick-liveness --root .`，两者都退 `0` 才算入网。入网后接受「3 批内至少改变 1 次动作」的淘汰考核。

## 四、收尾：这一轮的账怎么算

一轮接砖工作结束时，贴三样东西，缺一样不算完：

```text
① 缺口句：缺 <能力>，现在靠 <兜底>，补上后判据 <id> 从「无法判断」变成有读数
② 准入读数：check-declarations --verify-adapters → 0；check-brick-liveness --root . → 0
③ 真跑证据：.donegate/adapters/<tool>/claim.json 的路径与它的 claims 摘要
```

**不许只报「接好了」。** 接了但没改变任何判据读数的砖，按 `skill/15` （私有仓）§四 的判据算装饰，主动拔掉比留着好。

**诚实边界**（按 adr/007（调研/评审材料，不在公开分发包内） 降一档采信）：本技能让「接砖」这件事有固定动作与可判验收，但它**防不住**「适配器、判定核与夹具被同一个人同时改」的共谋，也**判断不了**你选的这块砖在你的业务上是否真的有意义——那一步只能由人担。
